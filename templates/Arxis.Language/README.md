# Перевод ArxisStudio

Папка — готовый языковой пакет: манифест и словарь. Ни сборки, ни кода в нём
нет и не нужно.

## Что делать

1. В `lang/xx.json` переведите **правые половины строк**. Ключи слева не
   трогайте: по ним студия и находит текст.
2. Непереведённое падает в английский, а не пропадает, — переводить можно по
   частям и дописывать позже.
3. Строка `language.name` — название языка на нём самом: его студия покажет в
   списке языков.

## Как попробовать

Скопируйте папку в каталог плагинов студии:

```
%APPDATA%/ArxisStudio/plugins/<id из манифеста>/
```

Язык появится в настройках сразу — перезапускать студию не нужно. На карточке
пакета в менеджере видно, сколько строк студии он закрывает.

## Как отдать другим

Соберите папку в zip и переименуйте в `.axplugin` — менеджер плагинов ставит
и архив, и папку.

## Перевести заодно и чужой плагин

В объявлении языка добавьте `translations`:

```json
"translations": [ { "id": "arxis.hello", "file": "lang/arxis.hello.xx.json" } ]
```

Ключи такого словаря — ключи самого плагина. Свой перевод плагина сильнее
вашего: автор знает про свой продукт больше.
