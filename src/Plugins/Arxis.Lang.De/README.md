# Arxis.Lang.De — пример языкового пакета

Пакет без единой сборки: манифест и два словаря. Ни `entry`, ни событий
активации — переводу нечего выполнять, и студия его не поднимает.

## Что он показывает

- **Часть строк студии.** Переведено около трети ключей — остальные падают в
  английский, а не пропадают. Так и выглядит живой перевод: студия растёт,
  словарь за ней догоняет. На карточке пакета в менеджере видно, сколько
  ключей закрыто.
- **Перевод чужого плагина.** `lang/arxis.hello.de.json` переводит панель и
  команду примера `Arxis.HelloPlugin`, который сам по-немецки не говорит.
  Свой перевод плагина был бы сильнее этого — автор знает про свой продукт
  больше.
- **Схождение веток меню.** Ключ `menu.tools` переведён одним и тем же словом
  и в словаре студии, и в словаре плагина. Ветки меню сходятся по
  переведённому тексту, поэтому встроенный модуль и внешний плагин
  оказываются в одном «Erweiterungsbefehle», а не в двух одинаковых с виду
  разделах. Назвав ветку иначе, пакет развёл бы их надвое.

## Как попробовать

Скопировать папку в каталог плагинов студии:

```
%APPDATA%/ArxisStudio/plugins/arxis.lang-de/
```

Deutsch появится в настройках сразу — перезапускать студию не нужно.

## Свой перевод

Начинать лучше с шаблона: он даёт **полный** список ключей студии с
английским текстом рядом.

```bash
dotnet new install templates/Arxis.Language
dotnet new arxis-language -n fr --display Français
```
