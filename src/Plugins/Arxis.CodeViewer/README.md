# Code Viewer — пробный плагин

Показывает текстовый файл решения на просмотр: подсветка по расширению, номера строк, цвет и
шрифт — ключами темы студии. Правку не умеет и не притворяется.

Плагин временный. Заведён он не ради просмотра файлов, а ради контракта: редактора документов
в репозитории не было ни одного, и дорогу «щёлкнули по файлу — открылась вкладка» держали
заглушки тестов. Появится настоящий редактор — этот уйдёт.

## Что на нём проверяется

- **Пробуждение по типу файла.** До первого `.cs`, `.axaml` или `.json` плагин спит:
  `onFileType:` в манифесте — часть контракта, а не оптимизация.
- **Своя зависимость.** AvaloniaEdit едет в пакете плагина и грузится его контекстом:
  общей сборкой студии она не становится — `Avalonia` узнаётся семейством, а не по первым
  буквам.
- **Отказ с причиной.** Файл крупнее половины мегабайта, не текст, не прочитался — студия
  несёт человеку слова плагина, ничего о них не зная.
- **Свои строки.** Словарь лежит в `lang/` рядом с манифестом; чужих ключей в нём нет.

Чем плагин платит за чужую библиотеку контролов — её оформление написано под тему, которой в
студии нет, а голые контролы Avalonia тема студии не одевает, — сказано в
[docs/plugin-markup.md](../../../docs/plugin-markup.md) и в записи 276 плана.

## Отладочная установка

```bash
dotnet build src/Plugins/Arxis.CodeViewer -p:AxPluginDeploy=true
```

Закрывать студию не нужно: выложите сборку и нажмите «Плагины → Перезагрузить».
