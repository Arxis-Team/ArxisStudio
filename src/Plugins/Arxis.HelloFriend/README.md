# Arxis.HelloFriend — пример плагина с зависимостью

Требует `arxis.hello` и показывает, что это даёт:

- **Порядок.** Манифест объявляет `dependencies: [ { "id": "arxis.hello", "min": "1.0" } ]`,
  и к моменту активации сосед уже стоит — его службы существуют, его команды
  заявлены. Без соседа плагин не поднимется вовсе и скажет почему.
- **Пробуждение.** Плагин нарочно отложенный (`onCommand:friend.cheer`).
  Пункт меню «Передать привет» будит его — а прежде него студия поднимает
  Hello. Та же дорога работает из кода: `Commands.Invoke` соседа тоже будит.
- **Служба соседей.** `GetService<IStudioPlugins>()` отвечает, активен ли
  сосед и какой он версии, — по манифесту, ничего не загружая. Обязательному
  соседу вопрос «есть ли ты» не нужен; служба нужна необязательным.
- **Каскад.** «Плагины → Перезагрузить · Hello» опустит и Friend, и поднимет
  обоих обратно в порядке графа.

Hello при этом остаётся примером обычного плагина без зависимостей — затем
их и двое.
